Released (v8.0.0)

New features and improvements

No new feature. 8.0 is a major version of symfony/options-resolver: like every major version, it only removes what was deprecated in 7.x. For symfony/options-resolver, defining nested options with a closure passed to setDefault() is no longer supported, use setOptions() instead (available since 7.3). The minimum PHP version is now 8.4.
