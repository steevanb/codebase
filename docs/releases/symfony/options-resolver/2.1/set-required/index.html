setRequired()

At a glance

Type
New feature
setRequired() added
2.1

Since symfony/options-resolver 2.1, setRequired() defines the options that must be given to resolve().

Required option setRequired()

Option given

  • Symfony 2.x documentation: Required Options
  • OptionsResolverInterface::setRequired() in v2.1.0
  • OptionsResolver::setRequired() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver->setRequired(array('firstName'));

// array('firstName' => 'foo')
$options = $resolver->resolve(array('firstName' => 'foo'));
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setRequired(['firstName']);

// ['firstName' => 'foo']
$options = $resolver->resolve(['firstName' => 'foo']);
