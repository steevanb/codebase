setOptional(array $optionNames)

At a glance

Type
New feature
setOptional() added
2.1

Since symfony/options-resolver 2.1, setOptional() defines options without a default value, only in the result when they are given.

Optional option

Option not given

  • Symfony 2.x documentation: Options without Default Values
  • OptionsResolverInterface::setOptional() in v2.1.0
  • OptionsResolver::setOptional() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver->setOptional(array('email'));

// array()
$options = $resolver->resolve();
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setOptional(['email']);

// []
$options = $resolver->resolve();
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver()
    ->setOptional(['email']);

// []
$options = $resolver->resolve();

use Symfony\Component\OptionsResolver\OptionsResolver;

Option given or not

An option not given is missing from the result, instead of being null: it tells whether the option was given.

  • Symfony 2.x documentation: Options without Default Values
  • OptionsResolverInterface::setOptional() in v2.1.0
  • OptionsResolver::setOptional() in v2.1.0

use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver->setOptional(array('email'));

// false
$hasEmail = array_key_exists('email', $options);

Then a default value

  • Symfony 2.x documentation: Options without Default Values
  • OptionsResolverInterface::setOptional() in v2.1.0
  • OptionsResolver::setOptional() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setOptional(array('key'))
    // The option is not missing anymore: it has a default value
    ->setDefaults(array('key' => 'foo'));

// array('key' => 'foo')
$options = $resolver->resolve();
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setOptional(['key'])
    // The option is not missing anymore: it has a default value
    ->setDefaults(['key' => 'foo']);

// ['key' => 'foo']
$options = $resolver->resolve();
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver()

// ['key' => 'foo']
$options = $resolver->resolve();

Required option

  • Symfony 2.x documentation: Options without Default Values
  • OptionsResolverInterface::setOptional() in v2.1.0
  • OptionsResolver::setOptional() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\Exception\MissingOptionsException;
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setRequired(array('key'))
    // The option stays required: setOptional() does not change it
    ->setOptional(array('key'));

// MissingOptionsException: The required option "key" is  missing.
$resolver->resolve();
use Symfony\Component\OptionsResolver\Exception\MissingOptionsException;
