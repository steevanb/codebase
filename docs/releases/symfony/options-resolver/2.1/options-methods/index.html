Options methods

At a glance.

Type
New feature
Methods added
2.1

Since symfony/options-resolver 2.1, Options can be used as a container of options: set, read and remove them, with lazy options evaluated when they are read.

Set an option set()

Value

PHP 5.3
$options = new Options();
$options->set('gender', 'female');

// array('gender' => 'female')
$all = $options->all();

Lazy value

A closure whose first argument is type-hinted Options is only called when the option is read, and can read the other options.

PHP 5.3
$options = new Options();
$options->set('firstName', 'John');
$options->set('gender', function (Options $options) {
    return 'John' === $options->get('firstName') ? 'male' : 'female';
});

// 'male'
$gender = $options->get('gender');

Overload an option overload()

The previous value of the option is passed to the second argument of the closure.

PHP 5.3
$options = new Options();
$options->set('roles', array('ROLE_USER'));
$options->overload('roles', function (Options $options, $previousValue) {
    return array_merge($previousValue, array('ROLE_ADMIN'));
});

// array('ROLE_USER', 'ROLE_ADMIN')
$roles = $options->get('roles');

Replace all options replace()

PHP 5.3
$options = new Options();
$options->set('firstName', 'Jane');
$options->replace(array('gender' => 'female'));

// array('gender' => 'female')
$all = $options->all();

Read an option get()

Option set

PHP 5.3
$options = new Options();
$options->set('gender', 'female');

// 'female'
$gender = $options->get('gender');

Option missing

PHP 5.3
$options = new Options();

// OutOfBoundsException: The option "gender" does not exist.
$gender = $options->get('gender');

Check an option has()

Option set

PHP 5.3
$options = new Options();
$options->set('gender', 'female');

// true
$hasGender = $options->has('gender');

Option missing

PHP 5.3
$options = new Options();

// false
$hasGender = $options->has('gender');

All the options all()

The lazy options are evaluated.

PHP 5.3
$options = new Options();
$options->set('firstName', 'John');
$options->set('gender', function (Options $options) {
    return 'John' === $options->get('firstName') ? 'male' : 'female';
});

// array('firstName' => 'John', 'gender' => 'male')
$all = $options->all();

Count the options count()

Options implements Countable.

PHP 5.3
$options = new Options();
$options->set('firstName', 'Jane');
$options->set('gender', 'female');

// 2
$count = count($options);

Remove an option remove()

PHP 5.3
$options = new Options();
$options->set('firstName', 'Jane');
$options->set('gender', 'female');
$options->remove('gender');

// array('firstName' => 'Jane')
$all = $options->all();

Remove all options clear()

PHP 5.3
$options = new Options();
$options->set('firstName', 'Jane');
$options->set('gender', 'female');
$options->clear();

// array()
$all = $options->all();

Read-only once read

Once an option is read, the options cannot be set, overloaded, replaced, removed or cleared anymore.

PHP 5.3
$options = new Options();
$options->set('gender', 'female');
$gender = $options->get('gender');

// OptionDefinitionException: Options cannot be set anymore once options have been read.
$options->set('gender', 'male');
