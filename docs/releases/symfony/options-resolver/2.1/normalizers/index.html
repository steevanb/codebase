setNormalizers(array $normalizers)

At a glance

Type
New feature
Method added
2.1

Since symfony/options-resolver 2.1, setNormalizers() transforms the resolved value of an option with a closure.

Normalize an option

Option given

  • Symfony 2.x documentation: Option Normalization
  • OptionsResolverInterface::setNormalizers() in v2.1.0
  • OptionsResolver::setNormalizers() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\Options;
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setRequired(array('email'))
    ->setNormalizers(array(
        'email' => function (Options $options, $value) {
            return strtoupper($value);
        },
    ));

// array('email' => 'FOO@BAR.COM')
$options = $resolver->resolve(array('email' => 'foo@bar.com'));
use Symfony\Component\OptionsResolver\Options;

$resolver = (new OptionsResolver())
    ->setRequired(['email'])

        'email' => function (Options $options, $value) {
            return strtoupper($value);
        },
    ]);

// ['email' => 'FOO@BAR.COM']
$options = $resolver->resolve(['email' => 'foo@bar.com']);
use Symfony\Component\OptionsResolver\Options;

Optional option not given

The normalizer of an optional option not given is called with null: PHP reports the undefined key, and the option is added to the result.

  • PHP 5.3 – 7.4A notice, Undefined index: email, then the normalizer receives null.
  • PHP >= 8.0A warning, Undefined array key "email", then the normalizer receives null.
  • Symfony 2.x documentation: Option Normalization
  • OptionsResolverInterface::setNormalizers() in v2.1.0
