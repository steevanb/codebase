isRequired()

At a glance

Type
New feature
isRequired() added
2.1

Since symfony/options-resolver 2.1, isRequired() tells whether an option is required and has no default value.

Required option isRequired()

Option unknown

  • OptionsResolverInterface::isRequired() in v2.1.0
  • OptionsResolver::isRequired() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();

// false
$isRequired = $resolver->isRequired('key');

Required option

  • OptionsResolverInterface::isRequired() in v2.1.0
  • OptionsResolver::isRequired() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver->setRequired(array('key'));

// true
$isRequired = $resolver->isRequired('key');
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())->setRequired(['key']);

// true
$isRequired = $resolver->isRequired('key');
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver()->setRequired(['key']);

// true
$isRequired = $resolver->isRequired('key');

  • OptionsResolverInterface::isRequired() in v2.1.0
  • OptionsResolver::isRequired() in v2.1.0

use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver

    ->setDefaults(array('key' => 'foo'));

// false
$isRequired = $resolver->isRequired('key');
