setDefaults()

At a glance

Type
New feature
setDefaults() added
2.1

Since symfony/options-resolver 2.1, setDefaults() defines options with a default value, used when the option is not given.

Default value setDefaults()

Null value

  • OptionsResolverInterface::setDefaults() in v2.1.0
  • OptionsResolver::setDefaults() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver->setDefaults(array('key' => null));

// array('key' => null)
$options = $resolver->resolve();
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())->setDefaults(['key' => null]);

// ['key' => null]
$options = $resolver->resolve();
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver()->setDefaults(['key' => null]);

// ['key' => null]
$options = $resolver->resolve();

Required option

  • OptionsResolverInterface::setDefaults() in v2.1.0
  • OptionsResolver::setDefaults() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setRequired(array('key'))
    // The option is not required anymore: it has a default value
    ->setDefaults(array('key' => 'foo'));

// array('key' => 'foo')
$options = $resolver->resolve();
