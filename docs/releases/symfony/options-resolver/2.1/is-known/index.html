isKnown($option)

At a glance

Type
New feature
isKnown() added
2.1

Since symfony/options-resolver 2.1, isKnown() tells whether an option is defined, with a default value, as required or as optional.

Known option

Option unknown

  • OptionsResolverInterface::isKnown() in v2.1.0
  • OptionsResolver::isKnown() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();

// false
$isKnown = $resolver->isKnown('key');

Option with a default value

  • OptionsResolverInterface::isKnown() in v2.1.0
  • OptionsResolver::isKnown() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver->setDefaults(array('key' => 'foo'));

// true
$isKnown = $resolver->isKnown('key');
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setDefaults(['key' => 'foo']);

// true
$isKnown = $resolver->isKnown('key');
use Symfony\Component\OptionsResolver\OptionsResolver;

    ->setDefaults(['key' => 'foo']);

// true

Optional option not given

An option missing from the result of resolve() is still known.

  • OptionsResolverInterface::isKnown() in v2.1.0
  • OptionsResolver::isKnown() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver->setOptional(array('key'));

// array()
$options = $resolver->resolve();

// true
$isKnown = $resolver->isKnown('key');
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setOptional(['key']);

// []
$options = $resolver->resolve();

// true
$isKnown = $resolver->isKnown('key');
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver()
    ->setOptional(['key']);

// []
$options = $resolver->resolve();

// true
$isKnown = $resolver->isKnown('key');

Numeric name

PHP turns the numeric keys of an array into integers: 42 and '42' are the same option.

  • OptionsResolverInterface::isKnown() in v2.1.0
  • OptionsResolver::isKnown() in v2.1.0

// true

$isKnown = $resolver->isKnown('42');

Array instead of a name

  • PHP 5.3 – 7.4An E_WARNING, Illegal offset type in isset or empty, then isKnown() returns false.
  • PHP >= 8.0A TypeError is thrown: Cannot access offset of type array in isset or empty.
  • OptionsResolverInterface::isKnown() in v2.1.0
  • OptionsResolver::isKnown() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver->setRequired(array('key'));

// E_WARNING: Illegal offset type in isset or empty
// false
$resolver->isKnown(array('key'));
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setRequired(['key']);

// E_WARNING: Illegal offset type in isset or empty
// false
$resolver->isKnown(['key']);
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver()
    ->setRequired(['key']);

// TypeError: Cannot access offset of type array in isset or empty
$resolver->isKnown(['key']);
