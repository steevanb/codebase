resolve(array $options = array())

At a glance

Type
New feature
resolve() added
2.1

Since symfony/options-resolver 2.1, resolve() merges the given options with the default ones and validates them: its argument is optional.

Resolve options

  • Symfony 2.x documentation: Usage
  • OptionsResolverInterface::resolve() in v2.1.0
  • OptionsResolver::resolve() in v2.1.0

// array()

Order of the options

Default values first

The default values come first, then the given options, whatever the order of the definitions.

  • Symfony 2.x documentation: Usage
  • Symfony 2.x documentation: Required Options
  • OptionsResolverInterface::resolve() in v2.1.0
  • OptionsResolver::resolve() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setRequired(array('firstName'))
    ->setDefaults(array('lastName' => 'foo'));

// array('lastName' => 'foo', 'firstName' => 'bar')
$options = $resolver->resolve(array('firstName' => 'bar'));
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setRequired(['firstName'])
    ->setDefaults(['lastName' => 'foo']);

// ['lastName' => 'foo', 'firstName' => 'bar']
$options = $resolver->resolve(['firstName' => 'bar']);
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver()
    ->setRequired(['firstName'])
    ->setDefaults(['lastName' => 'foo']);

// ['lastName' => 'foo', 'firstName' => 'bar']
$options = $resolver->resolve(['firstName' => 'bar']);

Steps of the resolution

Lazy option after the merge

A lazy option is evaluated once the given options are merged with the default values: it reads the given value.

  • Symfony 2.x documentation: Usage
  • Symfony 2.x documentation: Required Options
  • Symfony 2.x documentation: Default Values that Depend on another Option
  • OptionsResolverInterface::resolve() in v2.1.0
  • OptionsResolver::resolve() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\Options;
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setRequired(array('firstName'))
    ->setDefaults(array(
        'displayName' => function (Options $options) {
            return strtoupper($options['firstName']);
        },
    ));

// array('displayName' => 'FOO', 'firstName' => 'foo')
$options = $resolver->resolve(array('firstName' => 'foo'));
use Symfony\Component\OptionsResolver\Options;
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setRequired(['firstName'])
    ->setDefaults([
        'displayName' => function (Options $options) {
            return strtoupper($options['firstName']);
        },
    ]);

// ['displayName' => 'FOO', 'firstName' => 'foo']
$options = $resolver->resolve(['firstName' => 'foo']);
use Symfony\Component\OptionsResolver\Options;
use Symfony\Component\OptionsResolver\OptionsResolver;

    ]);

$options = $resolver->resolve(['firstName' => 'foo']);

Value and type not allowed

The allowed values are checked before the allowed types: the exception is about the value.

  • Symfony 2.x documentation: Usage
  • Symfony 2.x documentation: Required Options
  • Symfony 2.x documentation: Value Validation
  • Symfony 2.x documentation: Type Validation
  • OptionsResolverInterface::resolve() in v2.1.0
  • OptionsResolver::resolve() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\Exception\InvalidOptionsException;
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setRequired(array('firstName'))
    ->setAllowedValues(array('firstName' => array('foo')))
    ->setAllowedTypes(array('firstName' => 'int'));

// InvalidOptionsException: The option "firstName" has the value "bar", but is expected to be one of "foo"
$resolver->resolve(array('firstName' => 'bar'));
use Symfony\Component\OptionsResolver\Exception\InvalidOptionsException;

$resolver = (new OptionsResolver())

    ->setAllowedTypes(['firstName' => 'int']);
