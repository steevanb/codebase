isKnown() and isRequired()

At a glance.

Type
New feature
Methods added
2.1

Since symfony/options-resolver 2.1, OptionsResolver tells whether an option is known (declared with a default value, as required or as optional) and whether it is required.

Known option isKnown()

Option unknown

PHP 5.3
$resolver = new OptionsResolver();

// false
$isKnown = $resolver->isKnown('gender');

Option with a default value

PHP 5.3
$resolver = new OptionsResolver();
$resolver->setDefaults(array('gender' => 'female'));

// true
$isKnown = $resolver->isKnown('gender');

Required option

PHP 5.3
$resolver = new OptionsResolver();
$resolver->setRequired(array('gender'));

// true
$isKnown = $resolver->isKnown('gender');

Optional option

PHP 5.3
$resolver = new OptionsResolver();
$resolver->setOptional(array('gender'));

// true
$isKnown = $resolver->isKnown('gender');

Required option isRequired()

Option unknown

PHP 5.3
$resolver = new OptionsResolver();

// false
$isRequired = $resolver->isRequired('gender');

Required option

PHP 5.3
$resolver = new OptionsResolver();
$resolver->setRequired(array('gender'));

// true
$isRequired = $resolver->isRequired('gender');

Required option with a default value

PHP 5.3
$resolver = new OptionsResolver();
$resolver
    ->setRequired(array('gender'))
    ->setDefaults(array('gender' => 'female'));

// false
$isRequired = $resolver->isRequired('gender');

Optional option

PHP 5.3
$resolver = new OptionsResolver();
$resolver->setOptional(array('gender'));

// false
$isRequired = $resolver->isRequired('gender');
