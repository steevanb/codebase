addAllowedTypes()

At a glance

Type
New feature
addAllowedTypes() added
2.1

Since symfony/options-resolver 2.1, addAllowedTypes() adds allowed types to the ones set before.

Added types addAllowedTypes()

  • OptionsResolverInterface::addAllowedTypes() in v2.1.0
  • OptionsResolver::addAllowedTypes() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setDefaults(array('age' => 42))
    ->setAllowedTypes(array('age' => 'int'))
    ->addAllowedTypes(array('age' => 'string'));

// array('age' => '3')
$options = $resolver->resolve(array('age' => '3'));
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setDefaults(['age' => 42])
    ->setAllowedTypes(['age' => 'int'])
    ->addAllowedTypes(['age' => 'string']);

// ['age' => '3']
$options = $resolver->resolve(['age' => '3']);
