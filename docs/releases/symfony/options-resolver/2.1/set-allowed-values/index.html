setAllowedValues(array $allowedValues)

At a glance

Type
New feature
setAllowedValues() added
2.1

Since symfony/options-resolver 2.1, setAllowedValues() restricts the values of an option to a list.

Allowed values

Allowed value

  • Symfony 2.x documentation: Value Validation
  • OptionsResolverInterface::setAllowedValues() in v2.1.0
  • OptionsResolver::setAllowedValues() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setRequired(array('key'))
    ->setAllowedValues(array('key' => array('foo')));

// array('key' => 'foo')
$options = $resolver->resolve(array('key' => 'foo'));
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setRequired(['key'])
    ->setAllowedValues(['key' => ['foo']]);

// ['key' => 'foo']
$options = $resolver->resolve(['key' => 'foo']);
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver()
    ->setRequired(['key'])
    ->setAllowedValues(['key' => ['foo']]);

// ['key' => 'foo']
$options = $resolver->resolve(['key' => 'foo']);

Strict comparison

The values are compared with ===: the string '3' is not the integer 3, although the message shows both the same way.

  • Symfony 2.x documentation: Value Validation
  • OptionsResolverInterface::resolve() in v2.1.0
  • OptionsResolver::resolve() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\Exception\InvalidOptionsException;
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setRequired(array('key'))
    ->setAllowedValues(array('key' => array(42)));

// InvalidOptionsException: The option "key" has the value "42", but is expected to be one of "42"
$options = $resolver->resolve(array('key' => '42'));
use Symfony\Component\OptionsResolver\Exception\InvalidOptionsException;
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setRequired(['key'])
    ->setAllowedValues(['key' => [42]]);

// InvalidOptionsException: The option "key" has the value "42", but is expected to be one of "42"
$options = $resolver->resolve(['key' => '42']);
use Symfony\Component\OptionsResolver\Exception\InvalidOptionsException;
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver()

    ->setAllowedValues(['key' => [42]]);

Second call

The second call replaces the allowed values of the first one: use addAllowedValues() to add some.

  • Symfony 2.x documentation: Value Validation
  • OptionsResolverInterface::resolve() in v2.1.0
  • OptionsResolver::resolve() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\Exception\InvalidOptionsException;
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setRequired(array('key'))
    ->setAllowedValues(array('key' => array('foo')))
    // Replaces the allowed values of the first call
    ->setAllowedValues(array('key' => array('bar')));

// InvalidOptionsException: The option "key" has the value "foo", but is expected to be one of "bar"
$options = $resolver->resolve(array('key' => 'foo'));
use Symfony\Component\OptionsResolver\Exception\InvalidOptionsException;
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setRequired(['key'])
    ->setAllowedValues(['key' => ['foo']])
    // Replaces the allowed values of the first call
    ->setAllowedValues(['key' => ['bar']]);

// InvalidOptionsException: The option "key" has the value "foo", but is expected to be one of "bar"
$options = $resolver->resolve(['key' => 'foo']);
use Symfony\Component\OptionsResolver\Exception\InvalidOptionsException;
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver()
    ->setRequired(['key'])
    ->setAllowedValues(['key' => ['foo']])
    // Replaces the allowed values of the first call
    ->setAllowedValues(['key' => ['bar']]);

// InvalidOptionsException: The option "key" has the value "foo", but is expected to be one of "bar"
$options = $resolver->resolve(['key' => 'foo']);

Optional option not given, null allowed

An optional option not given is checked as null: when null is allowed, the option stays missing from the result, but PHP still reports its undefined key.

  • PHP 5.3 – 7.4A notice, Undefined index: key, then the option stays missing from the result.
  • PHP >= 8.0A warning, Undefined array key "key", then the option stays missing from the result.
  • Symfony 2.x documentation: Value Validation
  • OptionsResolverInterface::resolve() in v2.1.0
  • OptionsResolver::resolve() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setOptional(array('key'))
    ->setAllowedValues(array('key' => array(null)));

// Notice: Undefined index: key
// array()
$options = $resolver->resolve();
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setOptional(['key'])
    ->setAllowedValues(['key' => [null]]);

// Notice: Undefined index: key
// []
$options = $resolver->resolve();
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver()
    ->setOptional(['key'])
    ->setAllowedValues(['key' => [null]]);

// Warning: Undefined array key "key"
// []
$options = $resolver->resolve();

Optional option not given

The value of an optional option is checked even when the option is not given.

  • PHP 5.3 – 7.4A notice, Undefined index: key, then an InvalidOptionsException is thrown.
  • PHP >= 8.0A warning, Undefined array key "key", then an InvalidOptionsException is thrown.
  • Symfony 2.x documentation: Value Validation
  • OptionsResolverInterface::resolve() in v2.1.0
  • OptionsResolver::resolve() in v2.1.0

use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setOptional(array('key'))
    ->setAllowedValues(array('key' => array('foo')));

// Notice: Undefined index: key
// InvalidOptionsException: The option "key" has the value "", but is expected to be one of "foo"
$options = $resolver->resolve();
use Symfony\Component\OptionsResolver\Exception\InvalidOptionsException;
