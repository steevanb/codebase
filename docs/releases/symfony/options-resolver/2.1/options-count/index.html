Options implements Countable

Type
New feature

Since symfony/options-resolver 2.1, Options implements Countable: count() gives the number of options.

Count the options count()

Options counted

Options implements Countable.

PHP 5.3
use Symfony\Component\OptionsResolver\Options;

$options = new Options();
$options->set('firstName', 'foo');
$options->set('key', 'bar');

// 2
$count = count($options);
