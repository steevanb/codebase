Options::get($option)

At a glance

Type
New feature

2.1

Since symfony/options-resolver 2.1, Options::get() reads the value of an option.

Read an option

Option set

  • Declaration of Options::get() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\Options;

$options = new Options();
$options->set('key', 'foo');

// 'foo'
$key = $options->get('key');
