replaceDefaults(array $defaultValues)

At a glance

Type
New feature
replaceDefaults() added
2.1

Since symfony/options-resolver 2.1, replaceDefaults() replaces default values without passing the previous ones to the closures.

Replaced default value

Value

  • Symfony 2.x documentation: Usage
  • OptionsResolverInterface::replaceDefaults() in v2.1.0
  • OptionsResolver::replaceDefaults() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setDefaults(array('key' => 'foo'))
    // Replaces the default value of the first call
    ->replaceDefaults(array('key' => 'bar'));

// array('key' => 'bar')
$options = $resolver->resolve();
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setDefaults(['key' => 'foo'])
    // Replaces the default value of the first call
    ->replaceDefaults(['key' => 'bar']);

// ['key' => 'bar']
$options = $resolver->resolve();
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver()
    ->setDefaults(['key' => 'foo'])
    // Replaces the default value of the first call
    ->replaceDefaults(['key' => 'bar']);

// ['key' => 'bar']
$options = $resolver->resolve();

Previous closure

The previous closure is never called, which saves its cost when it is expensive: $previousValue is null (with setDefaults(), it would be called and the result 'foobar').

  • Symfony 2.x documentation: Default Values that Depend on another Option
  • OptionsResolverInterface::replaceDefaults() in v2.1.0
  • OptionsResolver::replaceDefaults() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\Options;
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setDefaults(array(
        'key' => function (Options $options) {
            return 'foo';
        },
    ))
    // Never calls the first closure: $previousValue is null
    ->replaceDefaults(array(
        'key' => function (Options $options, $previousValue) {
            return $previousValue . 'bar';
        },
    ));

// array('key' => 'bar')
$options = $resolver->resolve();

// ['key' => 'bar']
$options = $resolver->resolve();

use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setDefaults([
        'key' => fn (Options $options): string => 'foo',
    ])
    // Never calls the first closure: $previousValue is null
    ->replaceDefaults([
        'key' => fn (Options $options, ?string $previousValue): string => $previousValue . 'bar',
    ]);

// ['key' => 'bar']
$options = $resolver->resolve();
