setAllowedTypes()

At a glance

Type
New feature
setAllowedTypes() added
2.1

Since symfony/options-resolver 2.1, setAllowedTypes() restricts the type of an option: a PHP type (any is_*() function) or a class.

Allowed types setAllowedTypes()

An allowed type is the name of an is_*() function of PHP, without is_, or the name of a class or an interface:

  • array
  • bool
  • callable
  • countable (PHP >= 7.3)
  • float, double, real (PHP < 8.0)
  • int, integer, long
  • iterable (PHP >= 7.1)
  • null
  • numeric: an int, a float or a numeric string
  • object
  • resource
  • scalar: an int, a float, a string or a bool
  • string
  • any other is_*() function taking a single argument, e.g. file for is_file()
  • a class or an interface: the value is an instance of it (instanceof)

Type allowed

  • Symfony 2.x documentation: Type Validation
  • OptionsResolverInterface::setAllowedTypes() in v2.1.0
  • OptionsResolver::setAllowedTypes() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setRequired(array('age'))
    ->setAllowedTypes(array('age' => 'int'));

// array('age' => 42)
$options = $resolver->resolve(array('age' => 42));
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setRequired(['age'])
    ->setAllowedTypes(['age' => 'int']);

// ['age' => 42]
$options = $resolver->resolve(['age' => 42]);
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver()
    ->setRequired(['age'])
    ->setAllowedTypes(['age' => 'int']);

// ['age' => 42]
$options = $resolver->resolve(['age' => 42]);

Second call

The second call replaces the allowed types of the first one: use addAllowedTypes() to add some.

  • Symfony 2.x documentation: Type Validation
  • OptionsResolverInterface::setAllowedTypes() in v2.1.0
  • OptionsResolver::setAllowedTypes() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\Exception\InvalidOptionsException;
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setRequired(array('age'))
    ->setAllowedTypes(array('age' => 'int'))
    // Replaces the allowed types of the first call
    ->setAllowedTypes(array('age' => 'string'));

// InvalidOptionsException: The option "age" with value "42" is expected to be of type "string"
$options = $resolver->resolve(array('age' => 42));
use Symfony\Component\OptionsResolver\Exception\InvalidOptionsException;

Null instead of 'null'

The type is the string 'null': the value null is tested as a class name, whatever the value of the option.

  • PHP 5.3 – 5.6A fatal error, Class name must be a valid object or a string: it cannot be caught, the script stops.
  • PHP >= 7.0An Error is thrown: Class name must be a valid object or a string.
  • Symfony 2.x documentation: Type Validation
  • OptionsResolverInterface::setAllowedTypes() in v2.1.0
  • OptionsResolver::setAllowedTypes() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setRequired(array('age'))
    ->setAllowedTypes(array('age' => array(null, 'int')));

// Fatal error: Class name must be a valid object or a string
$options = $resolver->resolve(array('age' => 42));
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setRequired(['age'])
    ->setAllowedTypes(['age' => [null, 'int']]);

// Fatal error: Class name must be a valid object or a string
$options = $resolver->resolve(['age' => 42]);
use Symfony\Component\OptionsResolver\OptionsResolver;

    ->setRequired(['age'])
    ->setAllowedTypes(['age' => [null, 'int']]);

// Error: Class name must be a valid object or a string
