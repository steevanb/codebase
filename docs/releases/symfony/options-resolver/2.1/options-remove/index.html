Options::remove($option)

At a glance

Type
New feature
remove() added
2.1

Since symfony/options-resolver 2.1, Options::remove() removes an option, with its lazy value and its normalizer.

Remove an option

Option removed

  • Declaration of Options::remove() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\Options;

$options = new Options();
$options->set('firstName', 'foo');
$options->set('key', 'bar');
$options->remove('key');

// array('firstName' => 'foo')
$all = $options->all();
use Symfony\Component\OptionsResolver\Options;

$options = new Options();
$options->set('firstName', 'foo');
$options->set('key', 'bar');
$options->remove('key');

// ['firstName' => 'foo']
$all = $options->all();

Array syntax

Options implements ArrayAccess: unsetting an offset calls remove().

  • Declaration of Options::offsetUnset() in v2.1.0
  • Declaration of Options::remove() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\Options;

$options = new Options();
$options->set('key', 'foo');
// Calls $options->remove('key')
unset($options['key']);

// array()
$all = $options->all();
use Symfony\Component\OptionsResolver\Options;

$options = new Options();
$options->set('key', 'foo');
// Calls $options->remove('key')
unset($options['key']);

// []
$all = $options->all();

Set again

An option set again after its removal comes after the other options.

  • Declaration of Options::remove() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\Options;

$options = new Options();
$options->set('firstName', 'foo');
$options->set('key', 'bar');
$options->remove('firstName');
$options->set('firstName', 'baz');

// array('key' => 'bar', 'firstName' => 'baz')
$all = $options->all();

Option read by a lazy option

The lazy option is only evaluated when it is read: the option it reads no longer exists.

  • Declaration of Options::remove() in v2.1.0
  • Declaration of Options::get() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\Options;

$options = new Options();
$options->set('firstName', 'foo');
$options->set(
    'key',
    function (Options $options) {
        return strtoupper($options->get('firstName'));
    }
);
$options->remove('firstName');

// OutOfBoundsException: The option "firstName" does not exist.
$options->get('key');
use Symfony\Component\OptionsResolver\Options;

$options = new Options();
$options->set('firstName', 'foo');
$options->set(
    'key',
    fn (Options $options): string => strtoupper($options->get('firstName'))
);
$options->remove('firstName');

// OutOfBoundsException: The option "firstName" does not exist.
$options->get('key');

Its normalizer

Normalizer removed

remove() also removes the normalizer of the option: the value set again is not normalized.

  • Symfony 2.x documentation: Option Normalization
  • Declaration of Options::remove() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\Options;

$options = new Options();
$options->set('email', 'foo@bar.com');
$options->setNormalizer(
    'email',
    function (Options $options, $value) {
        return strtoupper($value);
    }
);
$options->remove('email');
$options->set('email', 'foo@bar.com');

// array('email' => 'foo@bar.com')
$all = $options->all();
use Symfony\Component\OptionsResolver\Options;

Normalizer without value removed

Without remove(), all() would call the normalizer and create the option.

$options->remove('email');

// array()

Read-only once read

Once an option is read, the options cannot be removed anymore.

Removed after a read

  • Declaration of Options::remove() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\Exception\OptionDefinitionException;
use Symfony\Component\OptionsResolver\Options;

$options = new Options();
$options->set('key', 'foo');
$options->get('key');

// OptionDefinitionException: Options cannot be removed anymore once options have been read.
$options->remove('key');
