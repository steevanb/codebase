addAllowedValues()

At a glance

Type
New feature
addAllowedValues() added
2.1

Since symfony/options-resolver 2.1, addAllowedValues() adds allowed values to the ones set before.

Added allowed values addAllowedValues()

Value added

  • Symfony 2.x documentation: Value Validation
  • OptionsResolverInterface::addAllowedValues() in v2.1.0
  • OptionsResolver::addAllowedValues() in v2.1.0
PHP 5.3
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setRequired(array('key'))
    ->setAllowedValues(array('key' => array('foo')))
    ->addAllowedValues(array('key' => array('bar')));

// array('key' => 'bar')
$options = $resolver->resolve(array('key' => 'bar'));
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = (new OptionsResolver())
    ->setRequired(['key'])
    ->setAllowedValues(['key' => ['foo']])
    ->addAllowedValues(['key' => ['bar']]);

// ['key' => 'bar']
$options = $resolver->resolve(['key' => 'bar']);
use Symfony\Component\OptionsResolver\OptionsResolver;

Allowed values set after

A later call to setAllowedValues() replaces the added values.

  • OptionsResolverInterface::setAllowedValues() in v2.1.0

PHP 5.3
use Symfony\Component\OptionsResolver\Exception\InvalidOptionsException;
use Symfony\Component\OptionsResolver\OptionsResolver;

$resolver = new OptionsResolver();
$resolver
    ->setRequired(array('key'))
    ->addAllowedValues(array('key' => array('foo')))
    // Replaces the added allowed values
    ->setAllowedValues(array('key' => array('bar')));

// InvalidOptionsException: The option "key" has the value "foo", but is expected to be one of "bar"
$options = $resolver->resolve(array('key' => 'foo'));
use Symfony\Component\OptionsResolver\Exception\InvalidOptionsException;

$options = $resolver->resolve(['key' => 'foo']);
