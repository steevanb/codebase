New capabilities added by this version.

  • Add OptionsResolverIntrospector::getDeprecationMessage() to get the deprecation message of an option
    Commit 87c209d741 Pull request #27667
  • Support nested options definition: setDefault() accepts a closure taking an OptionsResolver (and optionally the parent Options), and add isNested()
    Commit d04e40be5a Pull request #27291

Enhancements of existing features.

  • Make ExceptionInterface extend \Throwable

  • Pass the Options instance as first argument to the deprecation message closure of setDeprecated()
    Commit 29360510db Pull request #28738
  • Add a $triggerDeprecation argument to OptionsResolver::offsetGet() to read a deprecated option without triggering its deprecation
