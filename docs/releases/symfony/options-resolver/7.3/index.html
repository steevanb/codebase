New capabilities added by this version.

  • Add OptionsResolver::setOptions() and OptionConfigurator::options() to define nested options
    Commit b0bb9a12cc Pull request #59618
  • Add OptionsResolverIntrospector::getNestedOptions() to get the nested options closures of an option

Improvements.2

Enhancements of existing features.

    Commit 887757ef9b Pull request #59441

    Commit b0bb9a12cc Pull request #59618
