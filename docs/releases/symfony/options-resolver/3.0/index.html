BC breaks.4

Changes that can break existing code when upgrading from 2.8.

  • Remove the deprecated OptionsResolverInterface (use OptionsResolver instead)
    Commit 9b9158b4da Pull request #13407
  • Remove the deprecated set(), replace(), overload(), get(), has(), replaceDefaults(), setOptional() and isKnown() methods of OptionsResolver
    Commit 295bba297e Pull request #13808
  • Remove the deprecated OptionsResolver::setNormalizers() method (use setNormalizer())
    Commit 295bba297e Pull request #13808
  • Remove the deprecated array-of-options signature of setAllowedValues(), addAllowedValues(), setAllowedTypes() and addAllowedTypes(): the second argument is now required
    Commit 295bba297e Pull request #13808
