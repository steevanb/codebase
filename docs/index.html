What is new in your dependencies, with examples.

For each release of popular projects such as Symfony, Doctrine and more, codebase.watch lists the new features and improvements, and shows how to use them. No bugfix, no noise: only what changes the way you write code.

How it works.

  1. i.
    Compared to the previous version

    Each page compares a release to the previous one, component by component.

  2. ii.
    Features only

    New features and improvements of existing ones. Bugfixes and internal changes are left out.

  3. iii.
    From the source

    Built from the commits and the changelogs of each project, with links to them.
